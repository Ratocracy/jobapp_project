# Exploratory data analysis

The figures in this folder are generated by Spark aggregations and rendered
from the resulting small grouped tables:

```powershell
$env:PYTHONPATH = (Join-Path (Get-Location) "src")
python -m jobapps.pipelines.generate_eda
```

- `job_type_counts.png` shows the most common job types in the deterministic
  1% catalog sample.
- `document_length_distribution.png` compares the shared job and resume text
  contracts by word-count bucket.
- `eda_summary.json` records the sample size and summary/skills coverage used
  when the figures were generated.
